# 授權

本頁只記錄實際放進遊戲的檔案。

## 遊戲圖

`assets/sprites.png` 與 `assets/palette.txt` 為本專案自畫。石磚、藥架、燭臺的輪廓是按公開的剪影重繪進本專案色盤，倉庫裡沒有那些原檔。

## 字型

正文使用 Fusion Pixel 12px proportional，繁體版本，檔案是 `assets/fonts/fusion-pixel-12px-proportional-zh_hant.otf.woff`。

著作權人 TakWolf。授權 SIL Open Font License 1.1。全文在 `assets/fonts/OFL.txt`。這份字型沒有改過，仍使用原名 Fusion Pixel。

字型發行包附帶的上游聲明保留在 `assets/fonts/LICENSES/`（Ark Pixel、Cubic 11、Galmuri 的授權文本）。遊戲沒有另外載入這些字型檔。

## 沒有放進遊戲的素材

Sengoku Pixel Pack、未具名的 16x16 RPG Items、Galmuri 字型檔、Zpix，都不在這個倉庫裡。
